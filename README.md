# ClipboardCommander

Нативный менеджер буфера обмена для macOS. Живёт в строке меню, помнит последние 20 скопированных
текстов и картинок и открывается по **⌘⇧V** окном в стиле Spotlight.

- Написан на Swift / SwiftUI / AppKit: системный стеклянный фон, тёмная тема, шрифты и выделение как в macOS.
- Лёгкий: бинарник ~0,6 МБ, около 40–55 МБ памяти, без роста со временем.
- Картинки хранятся файлами, в памяти только маленькие превью.
- Пароли из менеджеров паролей не сохраняются.

Требуется macOS 14 Sonoma или новее.

---

## Как пользоваться

Копируйте как обычно (⌘C), а для вставки из истории нажмите **⌘⇧V**.

| Клавиша | Действие |
|---|---|
| печать | поиск по истории |
| ↑ / ↓ | выбрать запись |
| ↩ | вставить в программу, где был курсор |
| ⌘↩ | только скопировать в буфер |
| ⌘1 … ⌘9 | сразу вставить запись с этим номером |
| ⌘⌫ | удалить запись |
| esc | очистить поиск / закрыть окно |

- Двойной клик по записи вставляет её, правый клик открывает меню.
- Картинку из правой панели можно перетащить в Finder или в другую программу, и она сохранится файлом.
- В меню иконки в строке меню есть последние записи, очистка истории, папка с файлами
  и «Открывать при входе в систему».
- `open clipboardcommander://open` открывает окно из скриптов, Shortcuts или Raycast.

### Автовставка

Чтобы по ↩ запись сразу вставлялась в программу, ClipboardCommander нажимает за вас ⌘V.
Для этого macOS требует разрешения:
**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → ClipboardCommander**.
Без разрешения ↩ просто кладёт запись в буфер, а вставить её можно самому через ⌘V.

Глобальная горячая клавиша работает и без этого разрешения: она зарегистрирована через
`RegisterEventHotKey` и не перехватывает остальные нажатия.

## Где хранится история

`~/Library/Application Support/ClipboardCommander/`

| Путь | Что внутри |
|---|---|
| `index.json` | список записей: дата, источник, размер, начало текста |
| `items/` | содержимое: текст в `.txt`, картинки в `Изображение <дата>.png` / `.jpg` |
| `thumbs/` | превью картинок 256 px для списка |

- Хранится последние **20** записей. Чтобы изменить это число:
  `defaults write com.yarvod.clipboardcommander MaxItems -int 30`.
- Файлы вытесненных и удалённых записей удаляются сразу. При запуске удаляются файлы, на которые не ссылается ни одна запись.
- Повторное копирование того же самого не создаёт дубль, а поднимает запись наверх.
- Не сохраняются: содержимое с метками [nspasteboard.org](http://nspasteboard.org)
  (`ConcealedType`, `TransientType`: так помечают пароли 1Password, Bitwarden, Keychain и другие программы),
  а также скопированные в Finder файлы.
- История старой версии (`history.json`) переносится при первом запуске и переименовывается в `history.legacy.json`.

## Сборка

Нужны только Command Line Tools (`xcode-select --install`), Xcode не обязателен.

```bash
./build.sh
```

```bash
./build.sh --install
```

Первая команда собирает `dist/ClipboardCommander.app`, вторая ещё и кладёт его в `/Applications` и запускает.

| Переменная | Зачем |
|---|---|
| `ARCHS="arm64 x86_64"` | универсальная сборка для Apple Silicon и Intel |
| `CODESIGN_IDENTITY="Apple Development: …"` | подпись своим сертификатом |

По умолчанию сборка подписывается ad-hoc. macOS привязывает разрешение «Универсальный доступ» к подписи,
поэтому после каждой пересборки его придётся включить заново: выключить и снова включить переключатель.
С сертификатом разработчика (`CODESIGN_IDENTITY`) разрешение сохраняется.

Скрипт вызывает `swiftc` напрямую, без SwiftPM. `Package.swift` нужен только для автодополнения в Xcode и VS Code.

> Если `swiftc` падает с `redefinition of module 'SwiftBridging'`, значит Command Line Tools обновились
> не полностью. `build.sh` обходит это сам, а насовсем это лечится переустановкой:
> `sudo rm -rf /Library/Developer/CommandLineTools && xcode-select --install`.

Иконка рисуется скриптом из SF Symbol, менять её так:

```bash
swift scripts/make_icon.swift
```

Для разработки историю можно держать отдельно от настоящей:

```bash
CLIPBOARD_COMMANDER_DATA_DIR=/tmp/cc dist/ClipboardCommander.app/Contents/MacOS/ClipboardCommander
```

### Устройство

```
Sources/ClipboardCommander/
├── main.swift, AppDelegate.swift   — запуск, строка меню, горячая клавиша
├── Model/
│   ├── ClipItem.swift              — запись истории и пути к данным
│   ├── HistoryStore.swift          — история, лимит, файлы, перенос старой истории
│   └── ImageProcessor.swift        — сохранение картинок и превью (в фоне)
├── System/
│   ├── ClipboardMonitor.swift      — опрос NSPasteboard.changeCount
│   ├── HotKey.swift                — Carbon RegisterEventHotKey
│   └── Paster.swift                — запись в буфер и ⌘V
└── UI/
    ├── PickerController.swift      — плавающая панель, клавиатура
    ├── PickerView.swift            — интерфейс на SwiftUI
    └── Support.swift               — загрузка превью, иконки программ, форматирование
```

## Релизы

GitHub Actions (`.github/workflows/release.yml`) собирает универсальное приложение на `macos-15`.
По тегу `v*` оно публикуется в GitHub Release как `ClipboardCommander-<tag>-macos-universal.zip`.

```bash
scripts/release.sh --bump minor
```

Сборка подписана ad-hoc и не нотаризована. Если macOS не даёт открыть скачанный архив, снимите карантин:
`xattr -dr com.apple.quarantine /Applications/ClipboardCommander.app`.
