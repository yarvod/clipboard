# Changelog

Все значимые изменения этого проекта будут документироваться в этом файле.

Формат записей: секции по версиям, сгенерированные из истории коммитов между тегами.

## Не выпущено — нативная версия на Swift

- Приложение переписано на Swift / SwiftUI / AppKit вместо Python + PySide6 (Qt).
  Бинарник ~0,6 МБ вместо бандла PyInstaller, около 40–55 МБ памяти без роста со временем.
- Окно в стиле Spotlight: стеклянный фон, тёмная тема, список слева и просмотр справа,
  иконки программ-источников, превью картинок, контекстное меню.
- Хранится до 20 записей (`defaults write com.yarvod.clipboardcommander MaxItems -int N`).
  Файлы вытесненных записей удаляются сразу, «сироты» — при запуске.
- Картинки сохраняются файлами (`Изображение <дата>.png`), их можно перетащить из окна
  или показать в Finder; в памяти держатся только уменьшенные превью.
- Буфер проверяется по `changeCount` (раньше картинка перекодировалась в PNG каждые 0,4 с).
- Горячая клавиша через Carbon `RegisterEventHotKey` — без перехвата всей клавиатуры (pynput).
- Повторы не дублируются, а поднимаются наверх; пароли из менеджеров паролей
  (`org.nspasteboard.ConcealedType`) не сохраняются.
- Клавиши ↑↓, ↩ вставить, ⌘↩ скопировать, ⌘1–9, ⌘⌫ удалить, esc; автозапуск при входе;
  URL `clipboardcommander://open`.
- Старая история (`history.json`) переносится автоматически при первом запуске.
- Новая иконка, сборка `./build.sh` через `swiftc` (нужны только Command Line Tools),
  универсальная сборка arm64 + x86_64 в CI.
